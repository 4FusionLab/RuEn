# RuEn 0.4.0 — предварительная сборка

Буквенные сочетания русской раскладки обрабатываются по текущему списку `HotKey.List`. После настройки сочетаний список можно перечитать через команду RuEn в Fusion. Поддерживаются буквенные сочетания с модификаторами; ввод в проверенном текстовом поле остаётся русским.

Проверено в Fusion 2706.1.14 на macOS Apple Silicon: Extrude E/У, Line L/Д, Sketch Dimension D/В, текстовое поле Text Commands; отдельно проверены повторные события, Shift, незарегистрированное сочетание и отключение. Длительная работа, Windows, другие версии Fusion и все рабочие пространства не проверены. Ранее экспериментальные версии вызывали сбои Fusion; эта сборка не использует их механизмы, но ещё не прошла длительную проверку.
