# RuEn 1.0.0

RuEn — аддин Autodesk Fusion для использования назначенных буквенных горячих клавиш при русской раскладке. Он считывает назначения `HotKey.List` и сопоставляет русские клавиши с соответствующими латинскими; сами назначения Fusion не изменяются.

## Поддержка и ограничения

Поддерживаются macOS Apple Silicon и Windows x64. Обрабатываются зарегистрированные сочетания с одной латинской буквой и модификаторами, пока фокус находится в `QTCanvas`. Символьные и многошаговые сочетания не поддерживаются. После изменения назначений выполните **RuEn: обновить хоткеи**. Команда **RuEn: включить / выключить** управляет фильтром.

Фильтр использует внутренний класс Fusion `QTCanvas` и Qt, а не публичный API Autodesk; совместимость с будущими версиями Fusion не гарантирована.

## Установка

1. Скачайте архив релиза: `universal` для обеих ОС, `macos` для macOS Apple Silicon или `windows` для Windows x64. Универсальный вариант выбирает библиотеку по ОС автоматически.
2. Распакуйте архив, сохранив папку `RuEn` и её содержимое. Не перемещайте отдельные файлы из неё.
3. В Fusion откройте **Utilities → Add-Ins → Scripts and Add-Ins**, выберите **+ → Script or add-in from device** и укажите папку `RuEn`.
4. Выберите RuEn, нажмите **Run** и обязательно включите **Run on Startup**, чтобы аддин запускался вместе с Fusion.
5. В Design используйте назначенные сочетания при русской раскладке.

При обновлении с RuEnProbe остановите старый аддин в Scripts and Add-Ins, отключите его автозапуск и удалите старую запись, прежде чем добавить RuEn. Не запускайте обе копии одновременно. Идентификатор manifest сохранён; пользовательские назначения Fusion не изменяются.

Для удаления остановите аддин, отключите Run on Startup, удалите его запись в Fusion и распакованную папку. При ошибке загрузки проверьте соответствие архива ОС и наличие библиотеки рядом с `RuEn.py`.

## Разработка

Python-код находится в `RuEn/`, нативный фильтр — в `native/ruen_filter.cpp`. `python scripts/package.py` создаёт три ZIP в `dist/` из имеющихся библиотек; он не пересобирает их. Для macOS-сборки используйте `scripts/build_macos.sh` с `QT_SDK` для Qt 6.8.3; для Windows — `scripts/build_windows.ps1` в окружении MSVC x64 с совместимым Qt SDK (Qt 6.8.1). `experiments/native_filter_test.py` использует отдельное окружение PySide и не входит в поставку.
