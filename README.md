# RuEn

Аддин для Autodesk Fusion помогает использовать назначенные буквенные хоткеи при русской раскладке. Он читает текущий список через встроенную команду `HotKey.List`, сопоставляет русские буквы с английскими клавишами и передаёт Fusion только те сочетания, которые присутствуют в списке. Назначения Fusion не меняются.

## Установка

1. Распакуйте архив, сохранив папку `RuEnProbe` целиком.
2. В Fusion откройте **Utilities → Add-Ins → Scripts and Add-Ins**.
3. Выберите **+ → Script or add-in from device**, укажите папку `RuEnProbe` и включите её в списке.
4. В рабочем поле Design используйте назначенные хоткеи при русской раскладке. После изменения назначений в Fusion вызовите **Utilities → Add-Ins → RuEn: обновить хоткеи**. Команда **RuEn: включить / выключить** временно отключает и включает обработку.

Фильтр включается при запуске аддина. Автозапуск Fusion по умолчанию не включён; его можно включить в Scripts and Add-Ins.

## Границы этой версии

- Только macOS Apple Silicon и Fusion **2706.1.14**; на другой версии запуск блокируется. Нативный фильтр использует Qt Fusion и внутренний класс `QTCanvas`, которые не являются публичным API Autodesk.
- Обрабатываются только сочетания с одной латинской буквой и модификаторами Shift, Command, Option и Control, которые вернул `HotKey.List`. Символьные сочетания, многошаговые хоткеи и назначения, не попавшие в этот список, не преобразуются.
- Преобразование работает, только пока фокус у `QTCanvas`. Текстовые поля не обрабатываются. Проверены строка Text Commands, Extrude, Line и Sketch Dimension; другие элементы, рабочие пространства, собственные сочетания, длительная работа и Windows требуют дальнейшей проверки.
- При проверке предыдущих прототипов Fusion дважды завершился с ошибкой. Текущая версия заменяет проблемные реализации нативным фильтром; краткие проверки прошли, но длительная стабильность ещё не подтверждена.

## Разработка

Исходник — `native/ruen_filter.cpp`, Python-часть — `RuEnProbe/`. Библиотека собрана для arm64 с Qt 6.8.3 и использует библиотеки Qt, уже загруженные Fusion. Python-аддин не зависит от PySide. Сценарий `scripts/build_macos.sh` требует локальный SDK Qt 6.8.3 в `QT_SDK`.

Проверки: `python3 -m unittest discover -s tests -v` и `python3 experiments/native_filter_test.py` (последняя использует отдельное тестовое окружение PySide и установленный Fusion, а не входит в аддин).
